SF Pro Display setup

The stylesheet is already configured to load these files from this folder:
- SFPRODISPLAYREGULAR.OTF
- SFPRODISPLAYMEDIUM.OTF
- SFPRODISPLAYBOLD.OTF

Copy those three files from your own SF Pro Display archive into this folder.
The site will use SF Pro Display when the font files are present, and otherwise
fall back to the system sans-serif stack.
